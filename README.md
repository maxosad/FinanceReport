# FinanceReport

нажмите run_report чтобы сформировать отчет(report.xlsx) и контрольный файл (control_file)
либо наберите в терминале 
python report.py


Без проекта считается по всему файлу а не только по июню
Дубликаты считаются на полное соответствие и по всему файлу
amount меньше нудя считается по всему файлу 
Не классифицированные считаются только по периоду. (Из за того что сверка должна быть осмысленной. У нас отчет в определенном периоде, и мы доолжны брать первичку и некласифицированных в периоду )
